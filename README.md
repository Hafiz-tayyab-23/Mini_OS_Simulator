# Mini_OS_Simulator

A Java-based Operating System Simulator that demonstrates core OS concepts including CPU scheduling, memory management, process/thread handling, and synchronization through an interactive graphical user interface (GUI).

---

## 📌 Features

### 🖥 CPU Scheduling
- First Come First Serve (FCFS)
- Shortest Job First (SJF)
- Round Robin (RR)
- Process execution visualization

### 💾 Memory Management
- Memory allocation simulation
- Partition handling
- Memory usage visualization

### 🔄 Process & Thread Management
- Process creation and execution
- Multithreading concepts
- Thread lifecycle simulation

### 🔐 Synchronization
- Critical section handling
- Synchronization mechanisms
- Thread coordination concepts

### 🎨 Interactive GUI
- User-friendly Java Swing interface
- Real-time simulation panels
- Educational visualization of OS concepts

---

## 🛠 Technologies Used

- Java
- Java Swing (GUI)
- Object-Oriented Programming (OOP)
